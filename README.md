# Euro Total Multiservicios
Web estática de cinco páginas. Contacto: +51 904 631 279.

## Publicar en GitHub Pages
1. Extrae el ZIP en tu computadora.
2. En victormanuelzap/euro-total, elige Add file > Upload files.
3. Arrastra el CONTENIDO de esta carpeta (index.html, las cuatro páginas, assets y demás archivos), no el ZIP ni la carpeta contenedora.
4. Confirma con Commit changes. Puedes reemplazar el README inicial con este archivo.
5. Ve a Settings > Pages. En Build and deployment selecciona Deploy from a branch; rama main; carpeta / (root). Pulsa Save.
6. La dirección prevista es https://victormanuelzap.github.io/euro-total/ cuando GitHub termine la publicación.

No requiere instalar paquetes ni ejecutar un build. Se puede abrir index.html localmente.

## Editar
Los textos están en cada archivo HTML. El diseño está en assets/style.css. El menú está en assets/site.js.
Los enlaces de WhatsApp utilizan https://wa.me/51904631279 con mensajes para cada servicio.
Las imágenes se optimizaron a WebP sin modificar su contenido. La galería utiliza una selección de las imágenes recibidas; los renders y referencias de origen no confirmado no se rotulan como trabajos realizados.
La identidad del encabezado es tipográfica; el logotipo definitivo puede incorporarse después.
Antes de publicar, revisar descripciones de servicios y confirmar que se dispone de permiso para usar las imágenes seleccionadas.
